# 用語集（Glossary）

> プロジェクト横断で使われる業務用語の定義集。
> 各 spec の中で出てくる業務用語のうち、**複数の spec に跨がるもの**だけをここに置く。
> 個別 spec の中だけで使う用語は、その spec の「用語」セクションに書く。

ユビキタス言語（Ubiquitous Language）として、業務担当者・開発者・AI すべてが同じ言葉を使うための原本（[原則 P1](../../docs/concepts/mpa.md#p1-原本は一つ何でも一つにする)）。

---

## 投稿（Post）

ユーザーが書き込んだ単一のコンテンツ。本文・投稿者・投稿時刻を持つ。

- 一意の `PostId` で識別される
- 一度投稿された後、本文は編集できない（このプロジェクトの仕様）
- 削除は論理削除（物理削除しない）

## ユーザー（User）

このサービスを使う人。投稿の作成者・閲覧者・「いいね」を押す主体。

- 一意の `UserId` で識別される
- 認証されていない閲覧者は「ゲスト」と呼び、ユーザーには含めない

## いいね（Like）

ユーザーが投稿に対して付ける肯定的な評価。

- 1ユーザー × 1投稿 につき 1回まで（**二重いいね禁止**）
- 取り消し可能（unlike）
- 「いいね数（like count）」は投稿に対する集計値
