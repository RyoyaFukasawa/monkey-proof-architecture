# 投稿にいいねする

## 背景・目的

ユーザー同士が投稿に対して肯定的な反応を示せるようにする。SNS の最も基本的な相互作用であり、投稿の人気度を集計する基礎データにもなる。

## ゴール

認証済みユーザーが投稿に対して「いいね」を1回付けられ、取り消せる。同じ投稿に二重にいいねは付けられない。

## 用語

横断用語は [`../_glossary.md`](../_glossary.md) を参照。

- **二重いいね** — 同じユーザーが同じ投稿に対して2回以上いいねを付けようとする操作。仕様上は禁止される。

## 受け入れ基準（Acceptance Criteria）

### AC-1: 認証済みユーザーは未いいねの投稿に「いいね」を付けられる

- **前提**: ユーザー U がログイン済みで、投稿 P に対して U はまだいいねを付けていない
- **操作**: U が投稿 P に「いいね」を押す
- **期待結果**:
  - 投稿 P のいいね数が **1 増える**
  - レスポンスは **201 Created**
  - U の操作後の状態は「いいね済み」になる

→ [TODO](spec-001-like-post.todo.md#td-1)

### AC-3: 存在しない投稿へのいいねは 404 を返す

- **前提**: 投稿 ID `P` が存在しない（削除済みも含む）
- **操作**: ユーザー U が投稿 P に「いいね」を押す
- **期待結果**:
  - エラー: [`POST_NOT_FOUND`](../_errors.md#post_not_found)

### AC-4: 未認証ユーザーは「いいね」を付けられない

- **前提**: ユーザーが未認証（ゲスト）
- **操作**: 任意の投稿に「いいね」を押す
- **期待結果**:
  - エラー: [`UNAUTHORIZED`](../_errors.md#unauthorized)
  - 投稿のいいね数は変化しない

### AC-5: 「いいね」を取り消せる（unlike）

- **前提**: ユーザー U が投稿 P にいいねを付けている
- **操作**: U が投稿 P の「いいね」を取り消す
- **期待結果**:
  - 投稿 P のいいね数が **1 減る**
  - レスポンスは **204 No Content**
  - U の操作後の状態は「未いいね」になる

## 非ゴール（スコープ外）

- **いいねの通知** — 投稿者への通知機能はこの spec の範囲外（別 spec で扱う）
- **いいねの並び順** — いいねを押した順序の保持はしない
- **いいねランキング** — 人気投稿の集計・表示は別 spec
- **コメントへのいいね** — この spec は投稿（Post）にのみ適用される
